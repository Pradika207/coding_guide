# Training data

This directory contains development training data for the skill-prediction model.
The checked-in generator labels all generated records as
`synthetic_development_data`; these records are fictional and are not real
student data.

- `raw/` is the deterministic original CSV snapshot produced by the generator.
- `processed/` contains normalized training data and dataset metadata produced
  by the preparation stage.

The CSV outputs are generated by DVC and excluded from Git. DVC's local cache
retains their content for reproducible local runs. Do not put real user data in
this repository. A future MongoDB export can replace the raw snapshot while
keeping the preparation and training interfaces, provided it follows the
documented input columns and includes a truthful `training_source` value.
